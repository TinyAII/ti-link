# TI 联机 · 官网与更新源

这个仓库只放两样东西，**没有源码**：

| 文件 | 用途 |
|---|---|
| `index.html` + `shots/` | 官网页面（GitHub Pages，<https://ti.tinyaii.cn/>） |
| `latest.json` | 客户端「检测更新」拉的更新源 |

## latest.json 怎么改

发新版时改这两处，**客户端不用重新编译**：

```json
{
  "version": "1.1.0",          // 新的版本号；比客户端自己的大才会提示
  "url": "https://……",          // 让用户去哪里下载
  "note": "这版修了什么"         // 可选
}
```

⚠️ `version` 必须能被逐段解析成数字（`1.10.0` 这种两位数也没问题）。
写成 `1.1.0-beta` 之类客户端会认不出 —— 那时**宁可不提示**，也不会推错。

## 规矩（别破）

- 官网**不加载任何第三方脚本**、不做访问统计、不放广告、不加评论区
- 这个软件永远免费，这个页面也不该出现任何变现入口
- 更新只做**提示**，不做自动下载替换（无签名 exe 自我替换会被杀软当木马）
